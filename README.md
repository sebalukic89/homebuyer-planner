# Homebuyer Planner

## Problem

Buying a home requires comparing financial readiness, properties,
mortgage scenarios, and additional costs across multiple sources.

The Homebuyer Planner will organize those decisions in one application.

## Target user

Someone preparing to purchase a home who wants to understand affordability,
compare options, and organize the buying process.

## Initial features

- Create a financial profile
- Calculate mortgage payments
- Compare mortgage scenarios
- Estimate purchasing and closing costs
- Save properties under consideration
- Track home-buying tasks and deadlines

## Non-goals

- Provide professional financial advice
- Guarantee mortgage approval
- Submit real mortgage applications
- Supply real-time lender rates in the first version
